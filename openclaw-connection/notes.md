# OpenClaw Connection

- OpenClaw se configuró en un VPS para ejecutar el agente.
- Se conectó Telegram como canal de comunicación con el agente.
- Se configuró Zapier MCP para integrar servicios externos.
- Se utilizó mcporter para ejecutar acciones mediante Zapier.
- Se conectó Google Docs para crear y actualizar documentos.
- Se utilizó Google Calendar para gestionar eventos.
- Se verificó la creación y actualización del documento.
- Se resolvieron problemas de autorización OAuth y conexión mediante túnel SSH.

# Dificultades encontradas:
- La conexión de Zapier MCP requirió resolver problemas de autorización OAuth y configurar correctamente el callback mediante un túnel SSH entre Windows y el VPS.
